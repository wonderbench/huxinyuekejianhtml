# 平移与旋转 · 小小运动实验室

围绕教材第60—62页的模块1—5制作的交互课件，以教室电子白板授课为主要场景。先预测，再操作，最后说理由。

当前版本：**1.2.0 · 白板课堂与课后反馈版**。根据 [Oil UI](https://github.com/oil-oil/oil-ui) 的任务优先、视觉层级、可操作性与动效规则进行优化，设计取舍见 [DESIGN.md](DESIGN.md)。

## 直接使用

下载仓库 ZIP 并解压，用浏览器打开 **`index.html`**，即可使用五个教学活动和结尾的学习反馈。也可以只打开 **`feedback.html`** 收集课后反馈。

也可以只下载下列任意一个 HTML 文件。每个文件都内嵌了所需的样式、JavaScript 和 SVG 图形，单独保存后即可离线打开，不需要安装软件包或启动服务。

| 文件 | 活动 | 主要交互 |
| --- | --- | --- |
| [index.html](index.html) | 五个活动与课后反馈总入口 | 活动切换、教师提示、全屏演示、完成标记、结尾调查 |
| [modules/01-life.html](modules/01-life.html) | 生活中的运动观察站 | 六个生活场景，播放、暂停、慢速、观察线索、平移/旋转判断 |
| [modules/02-translation.html](modules/02-translation.html) | 平移实验台 | 自动门开关与方向预测；课本移动、路线比较、拖动验证 |
| [modules/03-rotation.html](modules/03-rotation.html) | 顺逆时针双向转盘 | 固定中心旋转、方向选择、经过位置预测、双路线对照 |
| [modules/04-overlap.html](modules/04-overlap.html) | 图案重合侦探 | 小狗与银杏叶；先选择，再用固定姿态的透明副本叠合验证 |
| [modules/05-clock.html](modules/05-clock.html) | 分针走了多久 | 从12出发顺时针走时、预测分钟、逐大格验证、隐藏/显示提示 |
| [feedback.html](feedback.html) | 课后学习反馈 | 两步自评、匿名填写、教师汇总、CSV/JSON导出及JSON合并导入 |

在 GitHub 文件页面可点击 **Download raw file / 下载原始文件** 保存 HTML；GitHub 的代码查看页不会直接运行课件。仓库文件可以部署到任意静态网站服务，`index.html` 是入口。本次交付不依赖在线托管。

## 课堂用法

1. 用“生活观察”导入，请学生先用手势表示，再分类。
2. 在“平移实验”中比较开门与关门的方向，并尝试三条课本移动路线。
3. 在“旋转转盘”中比较从 A 到 C 的顺时针、逆时针过程。
4. 在“重合侦探”中先预测，再用透明图案检验，并说出轮廓差异。
5. 在“分针计时”中把旋转过程与经过的时间联系起来。
6. 课末点击“填写课后反馈”，收集学生的收获、困难和想再练的内容。反馈不计入五个教学活动的完成数量。

### 电子白板的使用方式

- **白板大字默认开启。** 在宽度至少1000 CSS像素的课堂屏幕上，关键说明与反馈20px起，主要按钮至少56px高。右上角“白板大字”可切换普通字号；选择会在浏览器允许时保留。较窄窗口自动使用紧凑布局。
- **点按即可完成主要活动。** 课本可用路线与四角按钮移动；转盘可连续或逐站转动；重合可点“移到目标”，也可用64px方向按钮微调；分针预测可点“−5分钟／+5分钟”，无需实体键盘。原有拖动和输入仍可用。
- **对象与操作靠近。** 图案重合的目标、副本和六个候选图案在白板模式下分列左右；主要动作在画布附近。慢速、线索、轨迹和观察记录放在可展开区域。
- **按教学节奏暂停与继续。** 切换活动、切到其他浏览器页面时暂停动画；返回保留当前位置、预测和记录，不自动播放。逐站／逐格动画继续时仍只完成原来那一步。
- **先预测，再验证。** 主要按钮随阶段切换；错误保留学生原选择并指出修改方向。课本先选路线，再明确点“验证所选路线”。

右上角“教学提示”提供当前模块的提问顺序；“全屏演示”在浏览器支持时进入全屏。短屏不裁切教学内容，允许自然滚动。首次在实际白板上打开时，建议进入全屏并按本班观看距离确认文字大小。

当前练习状态仅在本次打开期间保留；刷新会重新开始练习。完成标记和字号模式可保存在当前设备，不支持本地存储时仍能正常使用。桌面活动导航支持方向键、Home、End移动焦点，再用Enter或空格进入；窄屏使用原生活动选择器。

## 课后反馈怎么收集

整合版导航的最后一项是“课后反馈”，“分针计时”页底部也有“填写课后反馈”入口。独立的`feedback.html`内嵌全部样式和脚本，单独保存即可使用。

### 学生填写

第一步针对五个目标选择“我会了／再练练／请帮我／今天没练过”。第二步选择学习感受，并可选填写想再练的主题、想对老师说的话、课堂／班级和学生代号。可以匿名，填写不计分；没有练过的活动不用猜测。

一位同学填写一份。保存后只显示感谢与“下一位同学填写”，不会在交接页展示上一位的留言。点击下一位会清空个人选择、代号和留言，并沿用课堂／班级。未提交的草稿在本次打开期间切换活动时保留。

### 老师查看与带走反馈

1. 切换到“教师汇总”，查看各目标四档自评、含求助的反馈、学习感受、想再练的主题和留言。
2. 按课堂／班级筛选，导出CSV逐份明细，或导出JSON备份。导出范围与当前筛选一致，时间使用北京时间。
3. 在其他设备填写时，分别导出JSON交给老师；老师在同一入口导入合并。相同编号的同一份反馈重复导入只计一次；答案相同但编号不同的反馈仍分别保留。
4. 清空本机全部反馈需要二次确认，且不限于当前筛选；先导出要保留的内容。

**收集方式：反馈保存在当前页面所在的浏览器中，没有服务器，不会自动上传到GitHub，也不会在学生手机与教师白板之间自动同步。** 正式收集请固定使用同一入口；不同入口、设备或浏览器之间用JSON导出和导入合并。浏览器数据被清除后不能依靠课件恢复，请在收集后导出备份。

统计单位是“份反馈”，不能直接等同于去重学生人数，也不是测验成绩。“今天没练过”单独列出，不计入该目标的有效自评；想再练的主题可多选，合计可能超过反馈份数。

保存失败时页面会明确显示“尚未保存”，保留本份答案，提供重试和下载本份JSON。原有存储损坏时不会静默覆盖，并提供原始内容备份。若浏览器禁止本地保存，可下载本份反馈，确认文件保存后再交给下一位；关闭或刷新页面会丢失尚未导出的暂存内容。

反馈仅由老师在浏览器中收集，仓库内不包含学生提交的数据。JSON文件上限5MiB，一次最多处理5000份反馈，超过时按课堂分批整理。

## 教学约定

- 指明实际观察部件：旗面整体、门扇、轿厢、扇叶、齿轮或抽屉。
- 平移可以沿水平、竖直或斜方向进行；课本移动时不旋转、不缩放。
- 旋转中心保持固定，方向基于统一的正面观察视角。
- 同一旋转终点可以由不同方向到达；保留经过位置与轨迹。
- 重合验证仅改变位置，保留原有朝向与大小，不自动旋转或翻转。
- 分针从12出发，按顺时针、一圈以内第一次到达目标位置来计时；每一大格为5分钟。钟面使用分针示意图。
- 原创 SVG 图形根据教材中的教学情境重新绘制，未将教材照片作为运行资源。

## 维护与构建

运行课件只需浏览器。修改源码后重新生成交付文件需要 Node.js：

```sh
node scripts/build.mjs
node scripts/check.mjs
node tests/behavior.mjs
node tests/feedback-data.mjs
node tests/feedback-ui.mjs
```

无需安装 npm 依赖。`src/core.js`管理模块生命周期与公共交互，`src/styles.css`提供统一布局，`src/modules/`保存活动和反馈页面。`src/feedback-data.js`负责反馈校验、统计和导入导出。构建脚本生成七份独立可运行的HTML。

```text
index.html                  五个活动与课后反馈总入口
feedback.html               独立课后反馈页
modules/                    五份独立 HTML
src/shell.html              页面结构
src/styles.css              公共视觉样式
src/core.js                 模块切换、生命周期与辅助函数
src/modules/                五个教学活动与反馈页的源码
src/feedback-data.js         反馈校验、统计、CSV/JSON处理
scripts/build.mjs           无依赖构建脚本
scripts/check.mjs           离线依赖、脚本语法与模块完整性检查
tests/                      无第三方依赖的DOM／事件仿真回归检查
```

## 验证范围

交付检查覆盖七份HTML的内嵌资源、脚本语法、模块完整性与离线依赖。原有33项DOM／事件仿真检查覆盖五个教学活动、状态保留、白板模式和生命周期。

新增11项反馈数据检查与15项反馈UI／事件检查，覆盖必填、自评统计、未练过的有效分母、JSON往返和冲突去重、CSV转义与公式防护、提交防重复、交接清空、班级筛选、导出范围、失败重试、损坏存储保护、暂存转保存、异步导入期间清空保护、退出后的晚到文件读取及下载失败提示。

独立结构审查与源码交互审查已完成。当前开发环境缺少浏览器预览服务的通信目录，无法完成真实浏览器排版、200%缩放或电子白板触屏实测；以上DOM检查不能代替这些验收。首次授课前，可在实际使用的浏览器与白板上依次检查：动画播放和暂停、课本拖动、顺逆时针路线、透明图案叠合、分针逐格计时，以及全屏显示。
